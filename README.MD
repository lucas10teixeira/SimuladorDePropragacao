🚀 Como executar
Este programa foi feito em linguagem C e pode ser executado no OnlineGDB ou em um editor como o VS Code (com compilador instalado).

No OnlineGDB:
Copie e cole o código no site.
Clique em "Run".
No seu computador (VS Code ou outro editor):
Compile o código (por exemplo, com o comando: gcc arquivo.c -o programa)
Execute com: ./programa
💡 Sobre o Programa
O programa simula a propagação de um vírus em uma população ao longo dos dias, considerando taxa de contágio, vacinação e eventos aleatórios.

📌 Observações
O código está no arquivo SimuladorDePropagacao.c (ou outro nome que usaram).
